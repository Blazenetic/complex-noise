# Fresh Agent Session

This file is a stable entry point, not a milestone handover.

1. Read `AGENTS.md`.
2. If available, use the repository skill at
   `.agents/skills/complex-noise/SKILL.md`.
3. Follow `docs/agent-operations.md` for orientation, task routing, validation,
   and handover.
4. Discover the newest applicable handover from the current branch and user
   request. Historical handovers do not grant current authority.

Do not encode a branch, commit, PR, or temporary milestone in this file. Put
that state in a dated or feature-specific handover instead.
