The site plan

The app ships as static files from GitHub Pages — no bundler, no runtime package, no build step (AGENTS.md, “What this is”). That makes the module graph the whole infrastructure diagram: there is no server tier to draw, because there isn’t one. What follows is that graph, at scale.

    02

    One frame, in fixed order

    js/still-field/loop.js is the only place a frame is defined. It runs at a user-chosen cap of 30, 45 or 60 fps — defaulting to 30, because this thing runs for eight hours on a phone. Because the cap is a setting, nothing inside may be expressed “per frame”: every decay, fade and smoothing is a rate per second run through 1 − exp(−rate · dt). Each stage below writes its own smoothed millisecond figure into telemetry, which is what the Code view of the in-app stats panel reads back.

    STAGE 0 · telemetry.msUpdate

    Update

    Audio metrics in; node step, depth projection and the spatial grid out. One pass over the population, then buildGrid().

    Links

    Flat pass first, then a rationed glow pass carrying shadowBlur. The glow pass stops at 10 nodes and is skipped outright under reduced motion, so nothing may be deferred to it unconditionally.

    03

    The one architectural rule

    State modules publish. app.js renders.

    audio.js, still-field.js, theme.js and ui-chrome.js each expose getState() and subscribe(fn). subscribe fires immediately with the current snapshot and again on every change. Event handlers never touch the UI.

    // Wrong: misses every change that
// has no click behind it.
btn.onclick = () => {
  audio.play();
  btn.innerHTML = PAUSE_ICON;
};

// Right: one render path, whatever
// caused the change.
btn.onclick = () => audio.play();
audio.subscribe(s => {
  btn.innerHTML = s.isPlaying
    ? PAUSE_ICON : PLAY_ICON;
});

    This is not taste. Playback stops on its own when the sleep timer fires, and updating the button inside its click handler is exactly how it ends up frozen on “pause” over silent audio at 3 a.m. That bug shipped once.

    AGENTS.md · guarded by tests/run.mjs

    One writer per shared object

    An imported binding is read-only in ES modules, so export let cannot be assigned across files. settings, view, world, grid, clock, telemetry, population and paint are each a plain object owned by exactly one module and read by many. On the plate they are the silos. To change one, you add a function to its owner — you never add a second writer.

    docs/still-field-architecture.md:88

    Imports point one way

    The renderer’s import graph is a DAG and must stay one. The leaves — math, clock, telemetry, grid, keep-outs, palette, view — import nothing from the field. stats.js is allowed to know about everything and is imported only by the front door. When a change would need a cycle, the shared thing wants its own module: modes.js exists for exactly that reason.

    docs/still-field-architecture.md:129

    Side effects compose in the front door

    A setter in settings.js clamps and persists, full stop. Knowing that a depth change also means remeasuring the world and then re-counting the nodes lives in js/still-field.js, where it reads as a list rather than a call chain.

    export function setStillFieldDepth(v) {
  prefs.setDepth(v);   // clamp + persist
  measureWorld(population.nodes.length);
  applyNodeCount();
  emit();              // tell everyone
}
    js/still-field.js:280–285
    04

    Load-bearing weirdness

    Several solids on the plate are shaped by a bug that already happened. These are the ones a reader of the diagram would otherwise assume were arbitrary.

    The analyser sits before the gain node

    So the visualisation tracks the noise itself, not the listening volume. Turning the volume down does not calm the field.

    stillEqLow → stillEqMid → stillEqHigh
   → analyser → gain → destination
    js/audio.js:189,203

    The buffer must be periodic, not merely long

    A 12-second buffer loops all night, so a filter started from zero state puts a step in the level every twelve seconds until morning. Every stateful generator runs a second pass over the head of its white-noise sequence to carry state round the join, and LFO rates come from lfoStep(), which rounds to whole cycles.

    js/noise.js:66–119

    Text and the trail cannot share a canvas

    #stillField subtracts alpha every frame with destination-out; a moving label drawn onto it leaves half a second of decaying copies of itself. All instrumentation goes on #stillFieldInfo, cleared outright, never blurred. Legibility comes from a plate behind the text, not a glow.

    AGENTS.md · docs/info-layer.md:19

    Canvas labels dodge the interface

    The canvas paints behind the controls, so a label under a card is a fillText nobody can see. app.js measures the chrome and pushes rectangles to setLabelKeepOuts() on resize, scroll, panel toggle and minimise — the renderer never measures the document itself, because a getBoundingClientRect per frame forces layout.

    js/app.js:488–510 → keep-outs.js:31

    A lazily allocated cache must be lazily released

    The source listing rasterises into an OffscreenCanvas — 434 KiB at DPR 1, 1.7 MiB at the DPR 2 cap. The first version was never freed, so a phone locked at 3 a.m. held it all night. layoutCodeTicker() releases it whenever the listing is not printing, and stopLoop() releases it on every way the loop can stop.

    code-ticker.js:174,222 · loop.js:218

    setTimeout is not a promise about time

    A backgrounded tab throttles timers to once a minute; a suspended phone does not run them at all. The sleep timer stores an absolute wall-clock timerEndsAt and treats the timeout as a hint, re-checking the deadline on every visibility change. The overshoot it prevents is the app playing for hours past the hour somebody asked for.

    js/audio.js:424–495
